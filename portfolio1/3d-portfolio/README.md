# 🚀 3D Portfolio (React + Vite + TypeScript)

A developer portfolio built with React, Vite, TypeScript, interactive 3D animations, and a space-themed aesthetic. Features an interactive 3D keyboard where each keycap represents a skill.

## 🛠️ Tech Stack

| Layer | Technologies |
|---|---|
| **Framework** | React 19, Vite, TypeScript, React Router DOM |
| **Styling** | Vanilla CSS, Tailwind CSS, Shadcn UI |
| **Animation** | GSAP, Framer Motion |
| **3D** | Spline Runtime |
| **Email** | Resend (Vercel Serverless Function at `api/send.ts`) |
| **MDX** | React Markdown + Vite Glob Imports |

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm, yarn, or pnpm

### Installation & Execution

1. **Install dependencies:**

    ```bash
    npm install
    ```

2. **Run the development server:**

    ```bash
    npm run dev
    ```

3. **Build for production:**

    ```bash
    npm run build
    ```

4. **Preview production build locally:**

    ```bash
    npm run preview
    ```
