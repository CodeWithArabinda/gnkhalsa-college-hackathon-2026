# Nilesh Gupta - 3D Interactive Developer Portfolio (Portfolio 1)

Welcome to the source code of my interactive 3D developer portfolio. This project showcases my professional skills, projects, and experiences in a high-fidelity, smooth interactive interface.

## 🚀 Technologies Used
- **Frontend Core**: React 19, TypeScript, Vite
- **Styling**: TailwindCSS, Sass, Radix UI
- **Animations & Interactivity**: GSAP (GreenSock), Spline (3D Scenes), Lenis (Smooth Scroll), Motion
- **Icons & Icons Library**: Lucide React, React Icons

## 🛠️ Installation & Setup

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### 1. Clone the repository and navigate to the directory:
```bash
cd portfolio1
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Run the development server:
```bash
npm run dev
```

### 4. Build for production:
```bash
npm run build
```

### 5. Preview production build:
```bash
npm run preview
```

## 📂 Project Structure
- `src/components`: UI components (radix buttons, tabs, modal dialogs).
- `src/assets`: Images, graphics, and static design assets.
- `src/styles`: CSS/Sass configuration and custom utility classes.
- `src/utils`: Helper functions and layout configuration constants.
