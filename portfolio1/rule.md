# Project Development Rules

These rules must be followed whenever modifying this portfolio project.

---

## 1. Understand Before Changing

Before modifying code:

1. Analyze the existing project structure.
2. Read `README.md`.
3. Read `DESIGN.md`.
4. Read `AGENTS.md` if present.
5. Read `CLAUDE.md` if present.
6. Inspect the relevant existing components.
7. Understand dependencies before adding new ones.
8. before implementing anything new check if that thing already there if not then implement

Do not immediately rewrite the project.
