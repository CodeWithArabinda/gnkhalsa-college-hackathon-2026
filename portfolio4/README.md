# Nilesh Gupta - Nuxt & Vue Developer Portfolio (Portfolio 4)

A responsive developer portfolio built with Nuxt 4 (Vue.js framework), TailwindCSS, AOS (Animate on Scroll) effects, and Highlight.js for code styling.

## 🚀 Technologies Used
- **Framework**: Nuxt 4 (Vue.js)
- **Styling**: TailwindCSS, Autoprefixer
- **Scroll Animations**: AOS (Animate on Scroll)
- **Syntax Highlighting**: Highlight.js, @highlightjs/vue-plugin

## 🛠️ Installation & Setup

Ensure you have [Node.js](https://nodejs.org/) installed.

### 1. Navigate to the project directory:
```bash
cd portfolio4
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Run the development server:
```bash
npm run dev
```

### 4. Build for production:
```bash
npm run build
```

### 5. Preview production build:
```bash
npm run preview
```

## 📂 Project Structure
- `pages`: Main Vue route pages (e.g. index, about, projects, contact-me).
- `layouts`: Global templates (header navbar, sidebar, footer).
- `components`: Reusable Vue layout elements (terminal widgets, buttons).
- `developer.json`: Nilesh's bio data, skills, project cards, and link setups.
